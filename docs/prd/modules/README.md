# Mini-PRD par module - Behar Tech Pro

Ces mini-PRD complètent le PRD global situé à la racine: `PRD_BEHAR_TECH_PRO.md`.

Chaque fichier est limité à un module et reprend la même structure:

- Objectif du module.
- Utilisateurs concernés.
- Problèmes à résoudre.
- Parcours utilisateur.
- Composants / écrans.
- Données nécessaires.
- Règles métier.
- Cas limites / erreurs à gérer.
- Critères d'acceptation.
- Tests obligatoires.
